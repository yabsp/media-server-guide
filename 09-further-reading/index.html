    Further Links & Related Guides

    This chapter collects the external resources, guides and references that informed this setup. They are a good starting point if you want to dig deeper into a specific topic or diverge from the choices made in this guide.

    Setup Guides & Platforms

    Broader guides covering full media server stacks and alternative platforms.

    • Docker Media Server (SmartHomeBeginner) — A comprehensive walkthrough of a Docker-based media server with 20+ apps.
    • Detailed Guide to Setting Up ZFS RAID on Ubuntu — An alternative storage approach to the MergerFS pool used in Storage Setup.
    • CasaOS — A simple, elegant open-source Personal Cloud system if you prefer a turnkey UI over a hand-rolled stack.

    Arr Apps & Automation

    Reference material for the Arr ecosystem and the tools that glue it together.

    • TRaSH Guides — Collection of Custom Formats (Radarr) — The de-facto standard for quality profiles and custom formats.
    • TRaSH Guides — How to set up Language Custom Formats — Useful for filtering releases by language.
    • Unpackerr — Documentation and Docker Image — Automatically extracts archived downloads for the Arr apps.
    • Bazarr (LinuxServer.io) — Companion app that manages subtitles for Sonarr and Radarr libraries.

    Plex

    Configuration, transcoding and troubleshooting resources for Plex.

    • Using Hardware-Accelerated Streaming (Plex Support) — How to enable and verify hardware transcoding.
    • Media Capabilities Supported by Intel Hardware — Reference for which codecs your Intel iGPU can decode/encode.
    • Plex Codec Issue (TrueNAS Community) — Troubleshooting thread for codec-related transcoding failures.
    • Can't access Plex from the Android app (r/PleX) — Fixes for the common "works in browser, not in app" problem.

    Alternative

    • Jellyfin — Does (basically) the same as Plex does but is open source (=> free).

    Usenet

    Guides and services for the download side of the stack.

    • PCJones Usenet-Guide (German) — An excellent German-language beginner's guide to the Usenet.
    • NZBGeek — A popular NZB indexer.
    • NzbPlanet — Another popular indexer which offers lifetime plan, good for english titles.
    • treasure-maps (SceneNZBs) — Another NZB indexer, popular choice for german audio.

    Common Usenet providers referenced during setup include TweakNews and Fast Usenet.

    Notifications

    • Gotify — A self-hosted server for sending and receiving push notifications, handy for wiring up alerts from your services.

    Streaming Technology (Further Reading)

    Background material for understanding how media streaming actually works under the hood.

    • howvideo.works — A concise primer on digital video and streaming.
    • FFmpeg (Trac) — Documentation for the tool underlying nearly all transcoding.
    • HTTP Live Streaming (Apple Developer) — The HLS specification and developer documentation.
    • HTTP Headers (MDN) and HTTP Authentication (MDN) — References for the HTTP layer used by proxies and APIs.
    • RFC 6749 — The OAuth 2.0 Authorization Framework — The authorization framework behind many service integrations.

    Legal

    • Swiss Copyright Act (URG), SR 231.1 — Art. 19 (Fedlex) — The Swiss legal basis for private-use copying. Know the rules that apply in your jurisdiction.
